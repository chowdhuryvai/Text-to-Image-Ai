## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/chowdhuryvai/Text-to-Image-Ai.git

# Navigate to directory
cd Text-to-Image-Ai

# Install dependencies
pip install -r requirements.txt

# Run the application
python Text-to-Image-Ai.py
